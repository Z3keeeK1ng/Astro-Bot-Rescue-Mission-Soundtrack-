## 🎮 About the Game

**Astro Bot Rescue Mission** (2018) is a 3D VR platformer developed by **Team ASOBI** (Japan Studio) and published by Sony Interactive Entertainment for PlayStation VR. 

Playing as Captain Astro, you embark on a journey across **5 distinct worlds** and **26 stages** to rescue your scattered crew of **213 Bots**, find hidden **Space Chameleons**, and defeat massive bosses using DualShock 4 VR gadgets like the Hookshot, Shuriken, and Water Cannon.

---

## ✨ Repository Features

- **🗺️ Complete Stage Walkthroughs:** Step-by-step guides for all 20 main stages and 6 boss battles.
- **🤖 Crew & Chameleon Tracker:** Interactive checklist to track all **213 Crew Bots** and **26 Hidden Chameleons**.
- **🏆 Challenge Belt Guide:** Tips and routes to earn Gold Medals on all 26 unlocked Challenge Stages.
- **🕹️ DualShock 4 Gadget Reference:** Breakdown of every controller gadget and its mechanics.

## 🛠️ Getting Started

If you are running this project locally (e.g., as a web tracker or static wiki):

1. **Clone the repository**
   ```bash
   git clone https://github.com
   cd astro-bot-rescue-mission
   ```

2. **Install dependencies** *(if applicable)*
   ```bash
   npm install
   ```

3. **Launch locally**
   ```bash
   npm run dev
   # Or open index.html directly in your browser
   ```
